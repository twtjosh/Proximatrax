# ProximaTrax

A web-based project management system for interior design and construction teams, bringing projects, tasks, schedules, files, and communication into one place.

## Getting started

```bash
git clone https://github.com/twtjosh/proximatrax.git
cd proximatrax
npm install
cp .env.example .env.local
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). A Supabase project is required; add its credentials to `.env.local`.

## Built with

Next.js, Supabase, and Tailwind CSS.
